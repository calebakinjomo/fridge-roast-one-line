My smart fridge needs a firmware update to remember it's a fridge — but it never forgets to judge my milk.

## Run it

```sh
node main.ts
```

This writes exactly one line to `/output/entry.txt` — a single roast of a smart fridge, 106 characters, no setup notes and no explanation.
